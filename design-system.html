Four Core Primitives

The card

card border-0 shadow-sm on a #f8fafc canvas, closed by a 3px semantic gradient bar.

The soft pill

Pale surface + 1.5px mid-tone border + AA-compliant foreground from one hue family. Never Bootstrap solid fills.

The section label

0.70rem uppercase, 0.08em letter-spacing, #94a3b8 with a leading icon.

The semantic colour

Every colour makes a semantic claim. If you cannot name what the hue means, use slate.

Six Non-Negotiable Principles

1. Colour carries meaning, not decoration. Blue = cash/edit, purple = online/print/video, teal = cheque/PDF, green = create, rose = destructive.
2. Solid Bootstrap contextual classes are banned. Never btn-primary, bg-danger, text-bg-*, or alert-*.
3. Unavailable states are shown with reasons, not hidden or muted silently. Use dashed slate pills/boxes with explanatory title text.
4. Every irreversible write passes through confirmation — and active tick + type-back where routine click-through causes errors.
5. Empty & loading states are designed. Dashed empty boxes with icons; slate shimmer skeletons before async data arrives.
6. State selectors belong in chemical.css, never inline. Inline styles defeat .active, :hover, :checked, and .collapsed.

2. Card Surface

Cards, modals, dropdown menus, app bar, and the side-nav inner column.

3. Inset Well

Read-only notes, empty states, dropzones — always paired with a solid or dashed #e2e8f0 rule.

4. Media Stage

Reserved strictly for video and rendered PDF canvases inside a media frame.

    • 
                                        
  • WCAG 2.1 AA contrast & neutral scale: Create foreground tightened #16a34a → #15803d (4.79:1); Destructive foreground on #fff1f2 tightened #e11d48 → #be123c (5.72:1); added slate-900 (#0f172a) & slate-700 (#334155); set #64748b (4.76:1) as the legibility floor for prose/helper/empty states.
    • 
                                        
  • Typography & data: Tabular numerals (.cc-num) and semantic Chart.js specification.
    • 
                                        
  • Forms, workflows & print: Inline field validation (.cc-invalid below .form-floating), vertical audit Timeline, responsive Stepper, declarative [data-cc-copy] feedback, and @media print unclipping rules.
    • 
                                        
  • Accessibility & security fixes: Keyboard Move up / Move down controls on reorder rows; DOM .text() construction fixing Step 1 XSS in confirmations; RequestVerificationToken + HTML-error-page guarding in Step 2 AJAX writes.
